# FPO Portal — Farmer Producer Organization Ecosystem

A static multi-page informational web portal on India's Farmer Producer Organizations (FPOs), covering:

- **Home (`index.html`)**: National overview and interactive **FPO Business Models** mind map.
- **10K FPOs (`history-scheme.html`)**: Evolution of the 10,000 FPOs Central Sector Scheme, financial norms, interactive **What an FPO Can Do** mind map, and 34-State/UT progress analytics.
- **14 Implementing Agencies (`implementing-agencies.html`)**: Roles, FPO allocations, headquarters locations, and official websites of all 14 IAs.
- **CBBOs & FPO List (`cbbos.html`)**: Cluster-Based Business Organizations (CBBOs), promoted FPO directory, and searchable state-wise FPO registry with an interactive entry/export tool.
- **Federations (`federations.html`)**: State-Level Producer Companies (SLPCs), national platforms, and an interactive Confederation Interest Form.

## Hosting on GitHub Pages

1. Upload all files inside this folder (`index.html`, `history-scheme.html`, `implementing-agencies.html`, `cbbos.html`, `federations.html`, `assets/`, `.nojekyll`, `README.md`) to your GitHub repository's root.
2. Go to **Settings → Pages → Build and deployment**.
3. Select **Deploy from a branch**, choose **`main`** and **`/ (root)`**, and click **Save**.
4. Your live site will appear at `https://<your-username>.github.io/<repository-name>/`.
